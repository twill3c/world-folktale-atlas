# 世界民話AIアトラス — World Folktale Atlas AI

> 権利を一件ずつ確かめた世界の民話 1,113 話を、多言語 Embedding で横断して眺めるアトラス。

30 冊・29 の文化圏・1,578,419 語。全話に出典 URL と権利状態と確認日が付いている。
サーバ関数もデータベースも定期実行も持たない。重い計算は手元で済ませ、
画面が読み込むのは計算済みの JSON だけである。

## 中心にある問い

> **機械が測る「物語の似かた」は、言語や本ではなく、物語そのものを見ているのか。**

このアトラスは、その問いに「はい」と答えるために作られていない。
**測って、答えが何であれ画面に出す**ために作られている。

「似ている民話が見つかる」という機能は、機械が物語ではなく**言語**や
**本の文体**を見ているだけでも、まったく同じように動く。画面も変わらず、テストも緑になる。
だから作る前に閾値を登録し、結果は落ちたものも含めて
[測ったこと](https://world-folktale-atlas.vercel.app/gates/)に全部出している。

| 主張 | 結果 |
|---|---|
| **H-01** 多言語 Embedding は言語ではなく物語を見ている | **✓ 通過** 交差言語 P@1 = 0.731(偶然の水準 0.016、閾値 0.50 は事前登録) |
| **H-02** 「似ている」は本の文体ではない | **！ 本の効果は大きい** 本内 vs 本間の効果量 Cohen d = 0.72 |
| **H-03** 地理的に近い文化圏の民話は意味的にも近い | **✓ 相関がある** r = 0.315、置換検定 p = 0.0002、有効標本は 28 冊。**ただし本と交絡し、r の大きさは一冊(ジャマイカ)に強く依存する** |

H-03 は設計書が価値として掲げていた前提である。**判定の帯(p < 0.01 で成立、0.01〜0.10 は保留)は
測る前に決めてあり、一度も動かしていない。** その帯のまま、本を足すたびに測り直してきた。

| 測った時点 | 有効標本 | r | p | 判定 |
|---|---|---|---|---|
| L1 | 11 冊 | — | 0.0496 | 判定できない |
| L4 | 21 冊 | 0.246 | 0.012 | 判定できない |
| L8 | 27 冊 | 0.231 | 0.001 | 相関がある |
| **L9** | **28 冊** | **0.315** | **0.0002** | **相関がある** |

- **変化は本を足した効果である。** 計算し直した Embedding のまま、L4 の 21 冊だけで測ると p = 0.012、L8 の 27 冊だけで測ると p = 0.0010 で、それぞれを再現した
- **同じ仮説を 4 回見ている。** 見るたびに偶然「成立」に入る機会は増える。4 回分として p を 4 倍しても 0.0008 で、帯の中にある
- **r の大きさはジャマイカ本に強く依存する。** 一冊抜きの r は 0.231〜0.341 で、最も動くのはジャマイカを抜いたとき(0.315 → 0.231)。
  ジャマイカ本はクレオールの聞き書き(`de`、`dat`、`anyt'ing`)で、本をまたぐ平均類似度が 30 冊中下から 2 番目
  (これより低いのは言語そのものが違う独語版グリムだけ)である。**綴りの違いで一様に遠く出る本が地理的にも遠い位置にある**ことが r を押し上げたと読むのが自然で、
  これを地理の証拠として数えない。ジャマイカを抜いた 27 冊でも p = 0.001 で、結論(帯の中)は一冊に依存しない

**それでも「地理が近いから似ている」とは言わない。** 地理は本(翻訳者・時代・編集方針)と交絡しており、
「地理が近いから似ている」と「たまたま近い土地の本どうしが似ている」は分離できていない。
本の効果も大きい(H-02、d = 0.72)。言えるのは、**本をまたいで比べても、地理的に近い文化圏の本どうしは
意味的にも近い傾向がある**、までである。

## 設計上の要点

### 1. 一冊が一地域に対応するコーパスでは、地理の発見は構成上の必然になりうる

『Folk-Tales of Bengal』はベンガル、『Philippine Folk Tales』はフィリピン。
つまり **同じ本の話が似る ⇒ 同じ地域の話が似る** が自動的に成り立つ。
翻訳者・編者の文体・語彙・組版は本単位で共通だからである。

実測すると、同じ本の話どうしの平均類似度 0.917 に対し、違う本どうしは 0.899(30 冊)。
効果量は **0.72(中〜大)**。よって

- 地理に関する主張は**本をまたぐペアだけ**で行う
- 近傍一覧には「同じ本／別の本」の札を必ず付ける
- つながり図は既定で本内の線を隠す

### 2. 分割の期待件数は、その本自身の目次から取る

民話集を一話ずつに割るのが本プロジェクト固有の難所である。
期待件数は**その本の目次が挙げる題名の数**(折り返し結合後 − 前付け)とし、
一致しない本は**コーパスに入れない**。採録した 30 冊すべてが一致した。

目次が無い本(『Aino Folk-Tales』)や、目次と本文の見出しの形が違う本では、
**著者が刷った通し番号**を使う。番号が 1 から欠けなく続くことと、目次があれば
その番号付き項目の数と合うことの**二つ**を突き合わせる(30 冊中 6 冊)。
連番だけだと、地の文の行頭の番号を見出しと取り違えても偶然続けば通ってしまう。

**話の単位は著者の番号に従う。** 『Jamaica Anansi Stories』は一つの番号の下に、別の語り手による
異話(a/b/c)を並べている。異話を別の話に割ると、近傍の 1 位が必ず兄弟の異話になるので、
番号 1 つを 1 話とし、異話はその中にまとめた。

一致しなかった 6 冊は落とした。取れた分だけ採ると、その本だけ話の切れ目が違うことになり、
以後の類似度がその差を測ってしまう。

### 3. 原資料と AI 推定を、色ではなく形でも分ける

<span>実線＝原資料から数えたこと</span> ／ <span>破線＝AI の推定</span> ／ <span>＃＝本文の語の数え上げ</span>

テーマとモチーフは Embedding による推定(`method: "embedding"`)。
動物・自然物・出来事は本文にその語があったかどうかの数え上げ(`method: "count"`)。
両者を同じ見た目で並べない。

### 4. ATU 分類は持たない。推定 ATU も出さない

権利上の問題なく参照できる対応表を確認できていない。
正式な既存分類と AI 推定を混同させないため、**推定 ATU を出すこともしない**。

## 踏んだ罠

| 罠 | 何が起きたか |
|---|---|
| **朗読音声を本文と間違えた** | PG 20050/20051/20972 は音声本で、`text/plain` は録音の README。**PG の START/END マーカーは両方ある**ので、マーカー検査だけでは弾けなかった |
| **目次の並びは本文の並びと違う** | 独語版グリムの目次はアルファベット順。単調増加を要求すると 62 件中 4 件しか一致しない |
| **最後の話に巻末が丸ごと入る** | 伝記・広告・巻末目次・奥付・PG 文言。**巻末が付くと話は長くなる**ので、語数の下限では絶対に捕まらない |
| **ドイツ語 62 話すべてでテーマが 0 件** | ラベル説明文が英語で、全話まとめて標準化すると独語が系統的に低く出る。→ HC-227 起票 |
| **件数は合うのに単位が混ざる** | ノルウェー本の目次 84 件は全一致したが、中身は序文の節・ノルウェーの話・**西インド諸島の付録**の三種混成だった |
| **上流確定前に 70 分の計算を始めた** | 話数が 730 → 709 に変わって計算を捨てた。→ HC-233 起票(検印で下流を止める) |
| **出来事推定が Family に 58%** | `father`/`mother` を生の回数で数えると、物語の構造ではなく語の頻度を測る |
| **日本のラベルが朝鮮半島の円に重なる** | ラベルどうしの衝突だけ見ていた。他の印の円も障害物にする必要があった |

## 作り方

```bash
py -3.14 -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt

# モデルの重み(この機の Python は huggingface.co を名前解決できないので curl で取る)
mkdir -p .models/multilingual-e5-small/onnx
for f in model.onnx tokenizer.json config.json tokenizer_config.json special_tokens_map.json; do
  curl -sL -o .models/multilingual-e5-small/onnx/$f \
    https://huggingface.co/intfloat/multilingual-e5-small/resolve/main/onnx/$f
done

.venv/Scripts/python etl/build_corpus.py   # 取得 → 分割 → 権利付与(件数オラクル照合)
.venv/Scripts/python ml/embed.py           # Embedding(5,147 チャンク)
.venv/Scripts/python ml/evaluate.py        # 目玉と対照の測定
.venv/Scripts/python ml/analyze.py         # 近傍・UMAP・HDBSCAN・テーマ・構造・緊張
.venv/Scripts/python etl/make_basemap.py   # 底図
.venv/Scripts/python etl/export_web.py     # 配布用 JSON

npm install && npm run verify              # 型検査 → テスト → ビルド
node harness/smoke.mjs --shot              # 実ブラウザ検品
```

### 和訳

全話の和訳を目指している。**いま 1,113 話中 591 話(53.1%)、語数で 46.4%。全 29 文化圏に 5 話以上あり、
イングランド(43 話)・朝鮮半島(53 話)・ヒマラヤ山麓(53 話)・グリーンランド(51 話)・北米先住民(32 話)・ユダヤ(25 話)・アイヌ(40 話)・ナイジェリア南部(40 話)・西アフリカ(36 話)・アゾレス諸島(33 話)・ウェールズ(24 話)・イベリア半島(21 話)・ブラジル(18 話)・ベーリング海峡(19 話)・南アフリカ(15 話)・中国(11 話)・フランス(10 話)・アイルランド(10 話)・ポーランド(7 話)は全話が日本語で読める。**
進捗は [和訳のすすみ](https://world-folktale-atlas.vercel.app/translations/) に出している。

和訳は **AI が作ったもの**であり(`translation_type: AI_GENERATED`)、原資料ではない。
**Embedding には入れない**(測定が汚れる)。**交差言語オラクルにも使わない**
(同じ本文の訳が原文を引き当てるのは当たり前で、何の証拠にもならない)。

和訳を足すときは、`data/translations/incoming/batch-NNNN.json` に
`{"STORY_ID": ["段落1", "段落2", ...]}` を書いて次を走らせる。
段落数が原文と合わない訳は取り込まれない。

```bash
.venv/Scripts/python etl/build_translations.py
.venv/Scripts/python etl/export_web.py
```

### 公開

**`git push` で自動的に本番へ出る。`vercel deploy` を打つ必要はない**(HC-256)。
CLI を重ねて叩くと、走っている正規のビルドと競合して `Upload aborted` を返すことがある。
**出荷できたかどうかは、道具の終了コードではなく公開 URL を引いて確かめる。**

```bash
node harness/live.mjs                      # 本番に対する検品(13 画面 + 全文検索)
```

## このアトラスが言わないこと

民話の歴史的起源 / 民族間の系統関係 / 伝播経路 / 宗教的・文化的優劣 / 国民性。
AI による分類・類似度・テーマ・感情・物語構造の推定は探索支援のための参考情報であり、
民俗学・歴史学上の確定的判断ではない。
