# L-DL1 — 出来事・モチーフの NLI 推定(2026-09-17)

## 問い

話の画面のモチーフは、e5 の説明文との近さ(言語ごとに z 化)と引き金語の数で出している。
多言語 NLI の零ショット推定に替えたら当たるか(SPEC §3 H-04)。

## 手順(順番が主張の一部)

1. モデルを**精度でなく**健全性 3 例と速度で選んだ
   - mDeBERTa-v3-base 量子化版: 「カエルが王子に変えられた」→「誰かが変身する」の含意確率 0.13、1.5 組/秒 → 不採用
   - MiniLM-L6(fp32): 健全、10.2 組/秒。int8 に量子化すると 19.8 組/秒だが含意確率が平均 0.128・最大 0.454 ずれる → fp32
2. ラベル 21 個・仮説文・判定の定義・合否の帯・対照を SPEC に書いてコミット(369240c)
3. 乱数で選んだ 45 話に、互いの答えを見ない二人の読み手(Claude サブエージェント 3 体ずつ)が付けた正解をコミット(a7ed035)。
   一致 905/945 項目(κ = 0.91)。「ある」の引用 654 件中 648 件が本文に字句どおりあった
4. 全 1,113 話・チャンク 5,809 個を推論(前後二つのプロセス、機の休止で 11 時間止まった)
5. 登録どおり判定

## 事後の診断(判定に使っていない)

- 陽性対照の一文**だけ**を前提にしても 21 ラベル中 13 で含意確率 < 0.5(桃から生まれる → 特殊出生 0.03)。
  長い本文に埋もれたのではなく、6 層のモデルが言い換えを一段推論しない
- チャンクの含意確率 ≥ 0.5 の割合は英語 0.280 / 独語 0.884。仮説文が英語で、独語の本文では系統的に高い。
  話の中の最大値で集約するので、長い話・独語の話はほぼ全ラベルが立つ
- H-04b の一致率が入れ替え平均と小数 4 桁まで同じだったのは評価の誤りではない。
  独語側が全ラベル付与なので、一致率はどの組でも英語側の付与率になる

## 検査が緑のまま通したもの

- **付与分布の検査(G-10 と同じ二条件)は飽和を通した**。全部に付ける分類器は無付与を作らず、最頻の占有率も下がる。
  全ラベル付与率と言語間の平均付与数の差を足し、全部 1・全部 0・正常の三つで検査器を検査する(HC-311)
- 幅 400px で対照表の値と合否が表の枠外に押し出されて見えなかった。ページの横溢れ検査は 0 のまま(GEN-LAYOUT)
- `harness/text_hygiene.py` の違反 142,058 件はすべて `.models/` の多言語トークナイザの語彙で、本体でも同数。
  この検査は gitignore の下の重みも走査している(このループでは直していない)
