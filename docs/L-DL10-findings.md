# L-DL10 — 語りの状態列(HMM)(2026-09-18)

## 問い

L-DL2 の「筋の形」は、順番の寄与を示せなかった。
**順番を明示的に扱う深層以前の道具(隠れマルコフモデル)なら示せるか**(SPEC §3 H-13)。

## やったこと

段落ごとに**数え上げだけの 6 特徴**(緊張語の差・会話の割合・平均文長・出来事の引き金語・
固有名の密度・語数)を作り、話の中で z 化し、5 状態のガウス HMM を EM(numpy で自前・30 反復)で学んだ。
**段落の位置は特徴に入れない。** 912 話・29,012 段落。

## 結果

| ID | 実測 | 判定 |
|---|---|---|
| H-13a 状態と位置の五分位 NMI | **0.003** | ✓ 位置の言い換えではない |
| H-13b 状態と本 NMI | **0.017** | ✓ 本の言い換えでもない |
| H-13c 独英グリム 18 組 | 対 0.626 / 対でない組 0.560、p = 0.062 | ✗(帯 p < 0.01) |
| 対照: 状態列を並べ替える | **0.632**(並べ替える前より高い) | 順番は効いていない |

## 読み取れたこと

- **状態は本にも位置にも縛られていない。** これは LDA のトピック(本との NMI 0.369)や
  e5 の群(0.690)と対照的である。**数え上げの特徴だけで作った状態は、訳者の書き方に引きずられにくい**
- **それでも、状態の並びで同じ話を言語をまたいで同定することはできない。**
  しかも並べ替えると似かたが上がる —— この指標が見ているのは
  「どの状態がどれだけ出るか」であって「どの順に出るか」ではない
- L-DL2 と同じ結論に、別の道具で到達した。**このコーパスでは「筋の順番」を測れていない**

## 設計で守ったこと

- K = 5 と特徴の一覧を学習の前に固定した
- 位置を特徴に入れない(入れれば H-13a は自動的に落ちる)
- 並べ替えの対照を最初から登録した。**これが無ければ「0.626 対 0.560」を成果と読み違えていた**
- 三つとも通ったときだけ画面に帯を出す、と決めてあったので**出していない**
