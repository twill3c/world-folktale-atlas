# L-DL13 — 文化圏ごとの指標の分布(2026-09-24)

## 作ったもの

「文化圏くらべ」に**分布の節**を足した。文化圏ごとに、数え上げの指標を
**横向きの箱ひげ図**(中央値・四分位・ひげ 1.5 IQR・外れ値)で出し、n を必ず併記する。
平均・標準偏差・中央値・四分位は折りたたみの表に併置した。

指標は 7 つ(すべて数え上げ):
話の語数 / 段落あたりの語数 / 平均文長 / 会話の割合 / 固有名の密度 /
動物・自然の語 / **和訳の長さ比**(全話の和訳がそろったので出せるようになった)。

32 文化圏・1,225 話・33 冊。新しく入った 3 冊(オーストラリア先住民・ニュージーランド(マオリ)・
フィリピン)も、本を足すだけで自動的に図に入る。

## 何が見えるか(そして何を読まないか)

- 話の長さの中央値は、アイルランド 5,122 語 ↔ アイヌ 423 語で 12 倍の開き
- 平均文長は 中国 30.5 語 ↔ アゾレス諸島 12.5 語
- **これは文化の性質ではない。** 一冊が一つの文化圏に対応するので、見えているのは
  その本の編者が何を選び、訳者がどう書いたかである。
  根拠は G-07(本内と本間の Cohen d)と Burrows の Delta(機能語だけで本の 7 割以上を当てる)

## 守ったこと

- **分位の二経路一致**: 自前の計算と numpy の `percentile` が最大差 7.1e-15(乱数 500 通り)
- 話数 10 未満の文化圏に ⚠ を出す(いまはポーランド 7 話だけ)
- 図は縮小せず枠の中で横に流す。幅 1280 と 400 で**文字の重なり 0・枠外 0**(HC-312 の網)
- 平均 ± 標準偏差の棒グラフにはしない。話数が 7〜136 と偏り、分布が右に裾を引くため
