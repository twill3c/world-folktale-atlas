# L-DL14 — 3 冊追加後の測り直し(2026-09-25)

## なぜやったか

本が 30 → 33 冊(1,113 → 1,225 話)に増えたあと、窓・ベクトル・筋の形・分布は作り直したが、
**「古い道具で測る」の二つ(TF-IDF の比較・HMM)を回し直していなかった**。
画面の数字は測定時のもので嘘ではないが、いまのコーパスと食い違う。取りこぼしなので直した。

## 結果

### 古典の比較(H-11)── 結論は変わらない

| 物差し | 2026-09-18(1,113 話) | 2026-09-25(1,225 話) |
|---|---|---|
| 半分割 TF-IDF / e5 | 0.915 / 0.804 | **0.919 / 0.799** |
| 交差言語 TF-IDF(固有名を落とすと) | 0.192(0.077) | 0.192(0.077) |
| Burrows の Delta(本の同定) | 0.749(29 冊) | **0.725(32 冊)** |

固有名は 1,664 → 1,786 語。**同言語では古典が勝ち、言語をまたぐと崩れる**という結論は不変。

### HMM(H-13)── **判定が変わった**

| ID | 2026-09-18(29,012 段落) | 2026-09-25(30,785 段落) |
|---|---|---|
| H-13a 状態と位置の NMI | 0.003 ✓ | 0.003 ✓ |
| H-13b 状態と本の NMI | 0.017 ✓ | 0.016 ✓ |
| H-13c 独英 18 組 | 対 0.626 / 対でない 0.560・p = 0.062 **✗** | 対 **0.739** / 対でない 0.600・p = **0.0002** ✓ |
| 並べ替えの対照 | 0.632(並べ替えると**上がる**) | 0.674(並べ替えると**下がる**) |

**三つとも通ったので、登録どおり状態の帯を画面に出した。**
独英の同じ話を上下に並べ、段落ごとの状態を色と番号で塗ってある。

## この変化をどう扱うか

- **帯は一度も動かしていない。** 前回の不成立も画面に残し、履歴として並べた
- **同じ主張を二度見た。** 多重性として p を 2 倍しても 0.0004 で帯(0.01)の中にある
- 変化の原因は本を 3 冊足して段落が 6% 増えたこと。H-03(地理と意味)でも同じ形の
  「本を足したら判定が変わった」を経験しており、そのときと同じ扱いにする
- **H-05 の「順番の寄与を示せない」は取り消さない。** あれは窓の Embedding の話、
  これは段落の数え上げ特徴の話で、別の物差しである

## 教訓

**コーパスが増えたら、下流の測定を全部数え直す。** 今回は 4 つ作り直して 2 つ忘れていた。
忘れた 2 つは画面に「測定時の話数」を出していたので嘘にはならなかったが、
読み手はいまのコーパスの数字だと思う。**作り直す対象の一覧を持つべきである。**
