# L-DL2 — 筋の形(2026-09-18)

## 問い

話を刻んで、意味が話の中でどう動くかを見ると、話全体を 1 本のベクトルにする今の近傍に無いものが取れるか(SPEC §3 H-05)。

## 手順

1. 窓 150 語・話の平均を引いて 8 点・窓 4 つ未満は形を持たない、と**計算の前に**登録してコミット(5f283ad)
2. 全 1,113 話の窓 10,519 個を e5 で埋め込み(1 話 1.1 秒)、対照用に 75 語ずらした独語版グリム 62 話も作った
3. 登録どおり判定

## 結果

| 項目 | 値 |
|---|---|
| 陽性対照(75 語ずらして切り直し) | P@1 1.000(54 話)✓ |
| 陰性対照(窓の順番を壊す) | P@1 0.040 ✓ |
| H-05a 形だけの交差言語検索 | 英語版グリム 58 話から 1.000、英語全 768 話から 1.000(p = 0.0001)✓ |
| 同じ相手を話全体の Embedding で | 0.720 |

| H-05c 本の効果(Cohen d) | 1.144(全体)→ 0.337(窓)✓ |
| **順番を使わない突き合わせ(事後)** | **P@1 1.000** |

## いちばん大事なこと ── 「筋の形」は測れていない

事前に登録した陰性対照(窓の順番を話ごとに壊す)は通った。しかし結果が良すぎたので、
**順番をまったく使わない**突き合わせ(位置を合わせず、窓どうしを互いに最も近い相手で比べる)を
事後に足したら、英語 768 話の中から**同じく 1.000**だった。

つまり効いているのは筋の順番ではなく、**話を刻んで細かく比べていること**である。
並べ替えで当たらなくなるのは、位置を合わせて比べる限り、中身が別の位置に移れば合わないからにすぎない。
登録した三つの主張は成立しているが、**「筋の形」という名前はこの測定が支える範囲より広い**。
画面の呼び名は「話を刻んで比べた近傍」にし、順番の寄与は示せていないと書いた(G-16)。

事前登録は「測る前に決める」ためのもので、**登録した対照が十分であることまでは保証しない**。
陰性対照を書くときは「この対照が通ったとき、通らない説明が他に残っていないか」を一度問う。

## 検査が先に捕まえたもの

- 動きの無い話(窓がすべて同じ)で、丸め誤差だけを正規化して**向きのあるベクトル**を作っていた。
  実データには出ない形だが、雑音が形として振る舞う。`FLAT_EPS` で弾き、形を持たないものとして扱う
- 公開データの検査を「全話に鍵がある」で書いて落ちた。短い話(窓 4 つ未満)は成立していても鍵が無いのが正しい

## 数の読み方

- 形を持つ話は 822 / 1,113。600 語に満たない話は比べていない
- H-05a の対は 25 組(形を持たない 1 組を除いた)。**26 組は小さい標本**で、P@1 1.000 は
  「この 25 組では 1 位だった」以上のことを言わない
- 実例: 灰かぶり(DE-2591-036)の近傍に、独語版 Aschenputtel・ノルウェーの類話・ペローのサンドリヨンが並ぶ
