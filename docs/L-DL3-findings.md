# L-DL3 — ブラウザ内の意味検索(2026-09-18)

## 問い

日本語の文で「こういう話」と書いて、1,113 話から探せるか。サーバも API も使わずに(SPEC §3 H-06)。

## 作ったもの

- `public/data/vectors.bin` … 話のベクトル 1,113 × 384 を int8 に量子化(417 KB)。量子化前との最小コサイン 0.999971
- `lib/semantic.ts` … ブラウザで問いをベクトルにして、配ったベクトルと比べる。問いの文は端末から出ない
- モデル(`Xenova/multilingual-e5-small` の量子化版)は **huggingface.co から実行時に読む**。
  リポジトリには置かない(1 ファイル 118 MB は GitHub の上限 100 MB を超える)
- `harness/semantic_check.mjs` … 本物の Chromium で 20 問 + 交差言語 30 問を流し、順位とベクトルを記録する

## 結果

読み込みは外部から 5.3 MB を 9 秒、1 問 77 ミリ秒(中央値)。

## いちばん大事なこと ── 問いの言語が文化圏を引き寄せる

同じ意味の問いを日本語と英語で書いて流した。1 位に日本の話が来たのは**日本語で 16/20、英語で 1/20**。
コーパスに日本の話は 22 話(2.0%)しかない。

つまり、日本語で問うと日本の民話ばかりが返る。これは H-01 で測った
「類似度の絶対値は言語を測り、順位は物語を測る」の、**問いの側での現れ**である。
この状態で機能を出せば、日本語の読み手には世界の民話ではなく日本の民話が並んで見える。

登録どおり **G-19 が落ちたので画面には出していない**(`show_on_site: false`)。
部品と測定はすべて残し、`/gates/` に結果を出した。帯は動かしていない。
