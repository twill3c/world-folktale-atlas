# L-DL9 — トピックモデル(LDA)(2026-09-18)

## 問い

深層以前のトピックモデル(LDA)で話を群に分けたら、何が出るか。
**このコーパスは一冊が一つの文化圏に対応する**ので、語で群を作れば
「トピック」と称して本を並べ直しただけのものが出やすい(SPEC §3 H-12)。

## 測ったこと

| 群の作り方 | 本との NMI |
|---|---|
| LDA のトピック(K = 12・固定) | **0.369**(帯 ≤ 0.35) |
| e5 の群(いま画面に出しているもの) | 0.690(未分類を除くと 0.764) |
| 同じ話だけで測った LDA | 0.394 |
| 無作為に 29 群へ分けたもの(偶然の水準) | 0.123 |

**H-12a は不成立。** 登録どおり、トピックは「文化ごとの主題」として読ませない。

## いちばん大事なこと ── 比べる相手が無い数は読めない

NMI 0.369 だけを見ても、大きいのか小さいのか言えない。同じ式で
**偶然の水準(0.123)と、いま画面に出している e5 の群(0.690)**を測って並べた。

読み取れるのは「LDA が特別に本へ寄っている」ではなく、
**この題材では語で分けても意味で分けても本が出る**ということである。
むしろ意味の側(e5)のほうが本に強く寄っている。

## トピックの中身

- `dey・dat・dem・tek・mudder` … ジャマイカの聞き書き一冊(重みの 96%)
- `thou・thee・thy・damsel` … 古い訳文の一冊(25%)
- `fish・sea・tortoise・leopard` … ナイジェリア南部(19%)
- `horse・girl・lad・palace・gold` … ロシア他(19%・半分を占めるのに 5 冊)

**綴りと訳語の癖が、そのままトピックになっている。**

## 設計で守ったこと

- K = 12 を測る前に固定した(良く見えるまで動かさない)
- 機能語(頻度上位 150)と固有名(大文字率 0.9 以上)を落とした。残り 7,695 語彙
- ドイツ語 62 話は混ぜない(語彙が別)
- 「重みの半分を占めるのに何冊要るか」をトピックごとに出した。1 冊ならその本の言い換えである
