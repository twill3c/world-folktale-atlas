## 1. 朗読音声を本文と間違えた(S2 / DATA-QUAL)

交差言語オラクル(H-01)の素材として独語版グリムと仏語版ペローを取りに行き、
**PG 20050 / 20051 / 20972 を「取得成功」と判定した。**

実際には三冊とも**朗読音声**で、`text/plain` が指していたのは録音の README だった。

```
Title: Märchen der Gebrüder Grimm 1
Subtitle: Reading by Rainer, Stefan Schmelz, …
***START OF THE PROJECT GUTENBERG EBOOK Märchen der Gebrüder Grimm 1***
This audio reading of … is read by
```

**PG の START/END マーカーは両方あった。** L0 で決めた検証(マーカーの有無)は
404 のエラーページは弾けるが、これは弾けない。気づいたのは本文が 4,193 字しか
なかったからで、**検証が通ったからではない**。

対策(`etl/fetch.py`):
- カタログに `audio/*` があれば拒否する
- `text/plain` の URL が `readme` を含めば拒否する
- ヘッダ・フッタを除いた本文が 20,000 字未満なら拒否する

代わりに **PG 77905『Deutsche Märchen gesammelt durch die Brüder Grimm』**(1921、62 話)を採った。

> フリートは同じ罠を一度踏んでいる(henshin-nuime: PG 26298 は朗読音声)。
> **「本文形式がある」ことは「本文である」ことを意味しない。**

## 2. 分割器の被覆を、実データ全域で四度測り直した

テストを書く前に実データ全域で被覆を測る(HC-069)。20 冊で測り、原因ごとに直した。

| 版 | 直したこと | 12 冊の一致 |
|---|---|---|
| probe 1 | 目次を見つけ、本文の単独行と照合する | 0/20 冊が 100% 近辺、多くが 25〜70% |
| probe 2 | `PAGE`/`Seite` を項目にしない・先頭の番号を落とす | 5 冊が 100% |
| probe 3 | **目次の順序を本文の順序と仮定しない** | 独語版が 6.5% → 95.2% |
| 実装 | 見出しを「空行で挟まれた**塊**」で索引する | 4018 / 77905 / 66923 の欠けが解消 |
| 実装 | 引用符で囲まれた題名・句点で終わる題名を弾かない | 26070 / 66923 / 77905 が 100% |

原因の内訳(すべて実測で特定した):

1. **目次の並びが本文の並びと違う。** 独語版 77905 の目次はアルファベット順である。
   単調増加を要求すると 62 件中 4 件しか一致しない。**順序制約を外した。**
2. **見出しが複数行に分かれる。**
   `THE STORY OF PRINCESS HASE` / `A STORY OF OLD JAPAN` のように 2 行に割れると、
   どちらの行も「前後が空行」を満たさない。行単位の索引では 4018 の 3 件・
   77905 の 3 件・66923 の 2 件が丸ごと見えなかった。**塊単位に変えた。**
3. **前付けを停止語にしてはいけない。** 目次の 2 行目が `PREFACE` である本(4018)で、
   目次全体を見失っていた。前付けは項目として拾い、`skip` で落とす。
4. **引用符・句点で終わる見出しがある。** `"THE WONDERFUL MAN"`(26070)、
   `“MORNING SUNRISE”`(66923)、`Die Drei Brüder.`(77905)。
   末尾の記号だけで弾くと、その話が丸ごと消える。
5. **目次は長い題名を折り返す。** 66923 の目次 47 行は題名 39 個だった。
   **件数オラクルは行数ではなく題名の数で数える。**

## 3. 件数オラクルの定義(SPEC G-03)

> その本の目次が挙げている題名の数(折り返し結合後)− 明示した前付けの数

抽出結果がこれと一致しない本は**コーパスから落とす**(`build_corpus.py` の既定)。
12 冊すべてが一致したので、落とした本は無い。

不一致だったため台帳に載せなかった本(参考):

| 本 | 理由 |
|---|---|
| PG-22373 Russian Fairy Tales (Ralston) | 民話集ではなく民話**論**。目次は章の要約で、話の題名ではない |
| PG-7439 English Fairy Tales (Jacobs) | 目次が流し組みで、1 行に複数の題名が入る |
| PG-12814 Philippine Folk Tales | 目次に群見出し(`Group I: Tinguian`)が混じり、17 件が本文と一致しない |
| PG-38339 South-African Folk-Tales | 8 件が一致しない |
| PG-23634 Italian Popular Tales | 目次が章立てで、話は章の中にある |
| PG-24473 / PG-33931 | 目次が本文から機械的に取れない |

**「取れた分だけ採る」ことはしなかった。** 一致しない本を混ぜると、
その本だけ話の切れ目が違うことになり、以後の類似度がその差を測ってしまう。

## 4. 最後の話に巻末が丸ごと入っていた

分割の境界は「次の見出し」しか見ない。**最後の話には次が無い。**
検査は全部緑のまま、次のものが本文に混ざっていた。

| 本 | 混ざっていたもの |
|---|---|
| PG-2591 | グリム兄弟の伝記(`*****` 区切りの後) |
| PG-29021 | 出版社の広告(`_Uniform with this Volume_`) |
| PG-77905 | **巻末の目次そのもの** |
| PG-22072 | 印刷所の奥付と翻刻者の註 |
| PG-51002 | `End of Project Gutenberg's Korean Folk Tales…` |

目視で末尾 60 行を読むまで気づかなかった。テストは「語数が下限以上」しか見ておらず、
**巻末が付いた話はむしろ長くなるので、下限では絶対に捕まらない。**

対策: 最後の話にだけ巻末マーカー(星の区切り・`THE END`・`Inhalt`・`Printed by`・広告)を当てる。
星の区切りは本文中にも出る(29021 に 3 件)ので、**最後の話にだけ**当てる。
翻刻者の註と PG の文言はどの話でも後付けなので全話に当てる。

註(`[45] Charm or incantation.` の連なり)は本文から切り離し、`notes` 欄に移した。
註は折り返されるので、`[n]` で始まる行だけを見ていると塊の途中で切れる。
