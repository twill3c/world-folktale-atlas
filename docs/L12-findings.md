## 2. 長い話を分けて書く — 部分番号つなぎ

アイルランド本の長い話は 1 万語を超え(IE-2892-010 は 477 段落・13,458 語)、一度に書き出せる長さに収まらない。
batch の鍵に部分番号を付けて分けて書き(`IE-2892-010#1` … `#4`)、取り込みで**番号順につないでから**検査にかける
`merge_parts` を L12 で入れた(テスト 2 件: 番号順につなぐ / 欠番は取り込まない)。

分けて書いた話は 7 話(中国 2・アイルランド 5)。

| 話 | 段落 | 部分 |
|---|---|---|
| CN-26070-005 | 90 | 2 |
| CN-26070-003 | 88 | 2 |
| IE-2892-007 | 237 | 2 |
| IE-2892-009 | 231 | 2 |
| IE-2892-002 | 310 | 4 |
| IE-2892-010 | 477 | 4 |
| IE-2892-001 | 148 | 1(分けずに書けた) |

**欠け方は二通りあり、止める検査が違う。**

- 途中が欠けた(`#1` と `#3` だけ)→ `merge_parts` が「1 から欠けなく続かない」でつながずに却下する
- **末尾が欠けた**(`#1` だけ)→ 番号は 1 から続いているので `merge_parts` は通す。つないだ訳は段落数が足りず、
  **T-JA-01(段落数の一致)が却下する**。実際に IE-2892-010 を 1 部分だけ書いた時点で取り込みを回すと
  「原文 477 / 訳文 86」で却下され、残りを書いたあとで通った

つまり末尾の欠けは部分番号の検査では見えず、段落数の検査に頼っている。段落数の検査があるかぎり取りこぼしは起きない。

## 4. 訳し方

- **中国本**(MacGowan)の固有名は広東系のローマ字綴りで、漢字が確かに当たるものだけ漢字にした
  (Sam-chung/Sam-Choang = 三蔵、Kwang-jui = 光蕊、Shih-Kung = 施公、Chang-lung = 張良、Yam-lo = 閻魔)。
  当てられないもの(Chiau / Chu)はカタカナにした。『西遊記』の猪八戒に当たりそうでも、綴りから確かめられないので漢字にしない
- **アイルランド本**(Stephens)は固有名をカタカナにし、原文の発音注(「Fionn [pronounce Fewn …]」)も訳して残した
- 章見出し(`CHAPTER I`)は「第一章」とした。原文の年(538 年・624 年)は算用数字のまま
- 詩の引用(「My wife is nicer than any one's wife …」)は段落の中に地の文と続けて訳した(原文も一段落)
