# L2 実測記録(2026-09-08)— Embedding と目玉の測定

モデル: `intfloat/multilingual-e5-small`(ONNX / CPU、384 次元)。
361 話を 300 語・重なり 50 語で切って 2,867 チャンク、語数で重みづけて集約した。

## 1. 目玉 H-01 は通った(G-05 ✓)

> **多言語 Embedding は「言語」ではなく「物語」を見ているか。**

同じ物語の独英対応 26 組(対応の根拠は目次の題名。モデルの出力ではない)で測った。

| 探す先 | 候補数 | P@1 | P@5 | MRR | 偶然の水準 |
|---|---|---|---|---|---|
| 英語版グリム 64 話 | 64 | **0.731** | 1.000 | 0.838 | 0.016 |
| コーパスの英語全話 | 299 | **0.654** | 0.808 | 0.740 | 0.003 |

閾値は 0.50 を**事前登録**していた(SPEC §3)。実測 0.731 で通過。
偶然の水準の 47 倍である。英語 299 話に広げても 0.654 で、
**話の同一性は本や言語の壁を越えて第 1 位に出る。**

### ただし言語の効果は確かにある

| 組 | 平均類似度 |
|---|---|
| 独語どうし | 0.939 |
| 英語どうし | 0.933 |
| 独語と英語 | **0.884** |

言語をまたぐと平均類似度が系統的に 0.05 下がる。
**類似度の絶対値は言語を測っている**が、**順位は物語を測っている**。
アプリでは絶対値ではなく順位で見せる根拠になる。

## 2. 二実装照合(G-06 ✓)

ONNX Runtime に前向き計算を任せきりでは、呼び出し方の誤りに気づけない。
ONNX ファイルから重みだけを取り出し、numpy だけで前向き計算を書き直して照合した
(`ml/embed_numpy.py`、埋め込み → 12 層 Transformer → LayerNorm、erf は A&S 7.1.26)。

| 比較 | 最大絶対差 |
|---|---|
| last_hidden_state | 1.04e-6 |
| 平均プーリング + L2 後 | 9.53e-8 |

閾値 1e-4(事前登録)を大きく下回る。

照合しているのは「モデルが正しいか」ではなく「**この呼び出し方が正しいか**」である。
次の三つは間違えても例外にならず、静かに違う数を返す。テストにした。

- パディングを attention から外し忘れる
- 平均プーリングにパディングを混ぜる(バッチに長い文が入ると全部が変わる)
- 長い話を切らずに入れて、後ろが黙って捨てられる

## 3. 「似ている」の正体の大半は本である(G-07)

| 組 | ペア数 | 平均類似度 |
|---|---|---|
| 同じ本の話どうし | 7,381 | 0.928 |
| 違う本の話どうし | 57,599 | 0.900 |

差 0.028、**効果量 Cohen d = 1.05(大)**。

一冊が一地域に対応する本コーパスでは、これを放置すると
「同じ地域の話は似ている」が**構成上の必然として**出てしまう。
よって地理に関する主張は**本をまたぐペアだけ**で行う(G-04)。画面にも両方を並べる。

## 4. 地理と意味の関係は「判定できない」(H-03 △)

設計書 §1.2 が価値として掲げる前提 —— **地理的に近い文化圏の民話は意味的にも近い** ——
を、本をまたぐ英語ペア 39,061 組だけで測った。

| 量 | 値 |
|---|---|
| 地理距離と意味距離の相関 r | **0.259** |
| 置換検定 p(5,000 回) | **0.0496** |
| 帰無分布の標準偏差 | 0.134 |
| 一冊抜きの r の範囲 | 0.193 〜 0.328 |

**p は 0.05 の真上に乗っている。これを「有意」と読んではいけない。**

- 検定の**単位はペアではなく本**である。39,061 を標本数として扱うと水増しになり、
  ほぼ必ず有意になる。有効な標本は **11 冊**しかない
- 帰無分布の標準偏差は 0.134 で、観測 r=0.259 はその 2 倍にすぎない
- 地理は本(翻訳者・時代・編集方針)と**完全に交絡**している。
  11 冊では「地理が近いから似ている」と「たまたまこの本たちが似ている」を分離できない

よって判定は **「判定できない」**。r は正の向き(近い文化圏ほど意味も近い)に出ているが、
**これを地図の上で「発見」として見せない。** 画面には r と p と一冊抜きの幅をそのまま出す。
