# L20 実測記録(2026-09-16)— アゾレス諸島を全訳に

**和訳 282 → 310 話(1,113 話中 27.9%)。語数で 358,652 → 393,097(24.9%)。**
**アゾレス諸島(Eells『The Islands of Magic』1922、33 話)が全訳になり、全訳の文化圏は 11。** 今回は 28 話・1,157 段落を訳し、取り込み検査の却下は 0 件だった。

---

## 1. 範囲

L19 のあと、未訳の語数が最も少ない文化圏はアゾレス諸島だった(28 話・34,445 語)。最長の話は PT-34431-004「長杖と松抜きと岩投げ」で、3,194 語・97 段落ある。これも一度に書ける長さだったので、部分番号つなぎは使っていない。3〜6 話ずつ 8 batch(0122〜0129)に分けて書いた。

## 2. 訳し方

- **既訳 5 話にそろえた**: どの話も、頭の段落が斜体の副題(`_The Story of ..._`)になっている。既訳にならい、斜体の記号を残して「_〜の話_」とした。地の文は「である」体、書き出しは「むかしむかし」
- **同じ著者の前の本と表記をそろえた**: Eells はブラジル本(L17)と同じ著者。ポルトガル語の通貨 vintem は、ブラジル本と同じくカタカナ「ヴィンテン」にし、初出に「(小銭)」と補った
- **意味で読む名前は訳した**: 次の名前は、筋が名の意味を使っているので日本語に訳した
  - 001 の Graywhite / Rosewhite / Bluegreen(灰白王・薔薇白妃・青緑姫)。結末で、姫の青い上靴と緑の日傘が「七つの町」の青の湖と緑の湖になる
  - 004 の Longstaff / Pinepuller / Rockheaver(長杖・松抜き・岩投げ)
  - 014 の Manoel Littlebean(豆つぶのマノエル)
  - 008 の Peter-of-the-Pigs は「豚のピーター」とした。英語の綴りは本のままカタカナに写し、Pedro と書かれた話(024)ではペドロとした
  - 029 の Perola は「ペローラ」とし、原文自身が「真珠という意味」と説明しているので、その説明をそのまま訳した
- **地名**: 実在する島や町の名(ファイアル・ピコ・テルセイラ・アングラ・オルタ・モンテ・ブラジル)はカタカナにした。英語名で書かれた St. Michael は、実在の島として「サン・ミゲル島」とした(026・001)
- **掛詞**: 028 には、IESVS MARIA の文字を並べ替えると _Maris es via_(汝は海の道なり)になる、というアナグラムがある。ラテン語の綴りを残し、意味を括弧で補った

## 3. 確かめたこと

- 数字の保存(T-JA-06)の対象になりうるのは、030 の「1666年」だけだった。段落の中に数字が 1 種類しかないので対象外だが、算用数字のまま残した。二十年・十二年・百フィートといった数は、原文で語として書かれているので漢数字にした
- 固有名は、どの話も原文を読んだその回のうちに訳した(L18 の写し違いへの対策)
