# L21 実測記録(2026-09-16)— ウェールズを全訳に

**和訳 310 → 329 話(1,113 話中 29.6%)。語数で 393,097 → 430,340(27.3%)。**
**ウェールズ(Griffis『Welsh Fairy Tales』1921、24 話)が全訳になり、全訳の文化圏は 12。** 今回は 19 話・897 段落を訳し、取り込み検査の却下は 0 件だった。

---

## 1. 範囲

L20 のあと、未訳の語数が最も少ない文化圏はウェールズだった(19 話・37,243 語)。最長は GB-9368-007「ウェールズの大いなる赤い竜」の 2,743 語・83 段落で、これも一度に書ける長さだったので部分番号つなぎは使っていない。2〜3 話ずつ 7 batch(0130〜0136)に分けて書いた。

## 2. この本の癖

Griffis の本は、ほかの 11 冊と性格がちがう。**昔話を語りながら、語り手が同時代(1921 年)のアメリカの読者に向けて注釈を入れる**からである。

- 電信・海底電線・無線電信・電球・蒸気船・電気の搾乳機といった当時の文明や、シェイクスピア、トマス・ジェファソン、第一次大戦のウェールズ連隊が地の文に出てくる。これを昔話らしく均さず、原文どおり訳した
- 語源や言葉遊びの注釈が多い。次の三つは、訳文だけでは意味が消えるので括弧で補った
  - 023 の Co-ed は、英語では「共学の女子学生」、ウェールズ語では「森」。原文が両方を使って洒落ているので、「コエド」と音を残して両方の意味を添えた
  - 014 のフクロウの鳴き声 "To whit, to who" は "to wit"(すなわち)と who(どなた)に掛けてある。「ホー、フー(どなた)」として掛けの両側を残した
  - 015 のマブ女王の名の遊び(Mab-gath =子猫、Mab-gar =子ども好き)も、意味を括弧で添えた
- 人名は本の綴りをカタカナに写した。Powell(『マビノギオン』のプイス)、Math(マース)、Gwyd(グウィド)、Rhiannon(リアノン)など、Griffis の綴りに従っている

## 3. 意味で読む名前

筋が名の意味を使っている名前は訳した。012 の Giant Tom / Giant Blubb は音のまま(トム巨人・ブラブ巨人)としたが、トムの本名 Rolling Stone は「転がる石」、022 の Red Bandits は「赤の盗賊団」、002 の Afang は音のまま「アヴァンク」とし、地名 The Pool of the Ox's Eye・Pass of the Oxen's Slope・The Lake of the Green Well は由来が語られているので意味で訳した(牛の目の池・牛の坂の峠・緑の泉の湖)。

## 4. 数字

T-JA-06(段落内に 2 種類以上の数字があるとき 1 つは残す)の対象になったのは 014 の 1 段落だけで、ウェールズ公の訪問年 **1919 年と 1860 年**が同じ段落にある。両方を算用数字のまま残した。三百年・四十くびき・三十七代目などは原文が語で書いているので漢数字にした。
