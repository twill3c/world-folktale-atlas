## 2. この本の性格と訳し方

Dracott はシムラ近郊の村で聞いた話を英語で書き留めた。藩王・バラモン・ファキール・バニヤ(商人)が繰り返し出てくるので、既訳 5 話の訳語に合わせた。

- **称号と身分**: Rajah は「藩王」、Ranee は「ラーニー(王妃)」、Fakir は「ファキール(行者)」、Bunniah は「バニヤ(商人)」、Vizier は「宰相」、Guru は「グル(導師)」、Hakeem は「ハキーム(医者)」
- **土地の言葉**: カタカナに意味を添えた(dooly ドゥーリー(輿)、chattie チャッティー(水壺)、goolgoolahs グルグラー、kheer キール(米を乳と砂糖で煮たもの)など)。訳文にラテン文字を残さないためでもある
- **言葉遊び**: 038 の ghuddee は著者が「ロバ」と「王座」の両義だと説明している。音は「ガッディー」のまま、著者の説明を訳した。015 の「アッチャー・バート」も著者の英訳を添えた形のまま訳した
- **教訓と注**: `Moral.--` は「教訓——」、`Note.--` は「注——」、033 の付記と 006 の注の署名 `--A.E.D.` は「エー・イー・ディー」とした。006 の注は著者が飢饉の年に引き取った娘の話で、「三インチ半」など数はすべて語で書かれていたので漢数字にした
- **脚注の参照番号**: `[1]`〜`[9]` は本文の位置のまま残した

## 3. 取りこぼしの確認

L22 で、読んだのに書き忘れた話が 3 つ出た。今回は取り込みの前に、index.json の未訳 ID から書いた batch の ID を引いて、**残りが空であることを確かめてから**ビルドした。この照合で、手元の「未読」一覧から 024(虎とネズミ)と 051(サルダナの伝説)の 2 話が漏れていたのが見つかった(一覧を作るとき写し落としていた)。取り込み後は `progress.json` のヒマラヤ山麓が 53/53 になったことを確かめた。

また、文脈の要約をはさんで作業を再開した直後に、原文が手元に表示されていない 6 話(020・011・009・012・028・045)の訳を書いていた。**書いたあとで原文を読み直して一段落ずつ照合し**、段落数と筋が合っていることを確かめた。直したのは 028 の二か所の言い回しだけだった。

L22 の書き忘れと今回の 2 件はどれも、残りの仕事の一覧をデータから導かずに記憶に持たせていたことから起きた。HARNESS_CHANGELOG に HC-301 として起票した。

ラテン文字 2 字以上の grep は、新しい batch 9 本で話の ID 以外に当たらなかった。
