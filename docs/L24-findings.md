## 2. この本の性格と訳し方

Rasmussen はグリーンランドの東岸・西岸・北のスミス海峡(イータ)で聞いた話を集め、英訳は語りの口調を残している。語り手の締めの句(「この話はこれでおしまい」「わたしはこれ以上知らない」)、「人の話では」の書き出し、「そう、話というものはいつもこう始まるのだ」(010)のような語り手の差しはさみは、みなそのまま訳した。

- **訳語は既訳 5 話に合わせた**: 鴉・カヤック・ウミアク、固有名は長音つきのカタカナ(クーニグセク・ナヴァラナー)。橇・銛・浮き袋・呼吸孔はそのまま漢字
- **霊と魔法**: wizard は「魔法使い」、spirit calling は「霊を呼ぶ儀式」、helping spirits は「助けの霊」、Tupilak は「トゥピラク」、inland-dwellers / tunerssuit は「内陸に住む者」(031 では「トゥネルスイト、つまり内陸に住む者」)
- **暴力と性**: 妻殺し、人食い、妻の貸し借り、子の産ませ方(004 冒頭)を、語りどおり和らげずに訳した
- **擬音**: 「フルルルル!」(041)、「レウ、レウ」(040)、「ずるっ」(012)は音の形を残した
- **脚注の参照番号**: `[2]`〜`[14]` は本文の位置のまま残した

## 3. 残りの一覧を記憶に持たせない(HC-301 の実施)

L23 で起票した HC-301 のとおり、残りの話は記憶に持たせず、書く前に index.json の未訳 ID − 書いた batch の ID で計算し直した。28 話を書いた時点で一度(残り 18)、004 の 4 部分を書き終えた時点でもう一度(残り 0)計算し、空を確かめてからビルドした。取り込み件数は 46 増えて 458、`progress.json` のグリーンランドは 51/51 だった。原文はすべて、訳を書く直前にその場で読んでいる。

書いた訳の読み直しで、007 の「なめにないめ」という打ち損じ 1 件を取り込み前に直した。ラテン文字 2 字以上の grep は、新しい batch 13 本で話の ID 以外に当たらなかった。
