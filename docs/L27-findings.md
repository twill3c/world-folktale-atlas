## 1. 範囲

L26 のあと、未訳の語数がいちばん少なかった文化圏は朝鮮半島だった(48 話・45,165 語)。一話は 1,000〜3,900 語で、段落の多い 053「タホン」(41 段落)と 001「チャラン」(30 段落)は、部分番号つなぎで `#1`・`#2` に分けて書いた。

## 2. この本の性格と訳し方

ゲイルが英訳した朝鮮時代の野談集(任埅・李陸の書いた話)で、多くの話の前に、登場する人物の略伝や道教・仏教・巫俗の説明が〔 〕で付いている。既訳 5 話に合わせて地の文は「である/た」調にした。

- **署名**: 話の末尾の「Im Bang.」は「任埅(イム・バン)」、「Anon.」は「作者不詳」とした
- **固有名**: 漢字表記が確かなもの(李恒福・鄭北窓・徐花潭・田禹治・林慶業・韓明澮・金瑬・李之菡・沈喜寿・盧守慎・任叔英・韓浚謙、地名の広寒楼・海印寺・鳥嶺・智異山など)だけを漢字(読み)で書いた。確かでないもの(イ・ウィシン、ユン・セピョン、パク・ウ、ホン・ネボムなど)はカタカナにした
- **原文が英語に訳した地名**: Ink Town・South Kettle Town・Belt Town は、もとの洞名を推し量らず「墨の町」「南の釜の町」「帯の町」とした
- **官職**: 既訳にならい、magistrate は「郡守」、provincial governor は「観察使」、Palace Secretary は「承旨」とした。021 の city の Governor と Mayor は、役目を推し量らず「知事」と「府尹」とした
- **注の番号**: 034 の [1]、035 の [2]、053 の [3] は、脚注本文がこの版に無いため〔注一〕〔注二〕〔注三〕として位置だけ残した
- **数字**: 年が二つ以上ある段落(016 の 1596/1623/1624/1648、025 の 1601/1605/1623、035 の 1561〜1644、053 の 1570/1572/1589 など)は T-JA-06 のとおり算用数字にした。一つだけの段落は既訳と同じく漢数字にした

## 3. 取りこぼしの確認と、また原文の無いまま書いた件

HC-301 のとおり、残りは batch を書き進める途中とビルド前に、index.json の未訳 ID − 書いた batch の ID(部分番号を外して数える)で計算し、残り 0 を確かめてからビルドした。取り込み件数は 48 増えて 553、`progress.json` の朝鮮半島は 53/53。ラテン文字 2 字以上の grep は、新しい batch 9 本で話の ID 以外に当たらなかった。段落数と「数が二つ以上ある段落に算用数字が残っているか」は、原文の段落ごとに照合した(不一致 0)。

**ただし、文脈の要約をはさんで再開した直後、要約に「読んだ」とあった 8 話(batch-0197)を、原文が文脈に無いまま書いた。** HC-301 が名指しする ② の型で、このプロジェクトでは 2 回目(CTX-ROT 累計 4 回目)。書いた直後に原文を読み直して段落ごとに照合し、段落数と筋は 8 話とも合っていたが、次の 4 点を直した。

- 015 の風水師の名に、確かでない漢字「李懿信」を当てていた → 「イ・ウィシン」
- 015 の「male choice / female choice」を「陽宅/陰宅」と解釈で書いていた → 「男の選び」「女の選び」
- 036 の Ink Town・South Kettle Town に、確かでない洞名「墨洞」「南釜洞」を当てていた → 「墨の町」「南の釜の町」
- 032 の「側室の子で自分の実の母ではない大妃」は、側室の子が大妃のほうに読めた → 「自分は側室の生まれで、実の母ではない大妃」

**害が小さかったのは、書いた後に原文と照合したからで、要約の「読んだ」が内容を運んでいたからではない。** 直したところはどれも取り込み検査(段落数・長さの比・数字)を通る形だった。
