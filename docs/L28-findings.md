## 2. この本の性格と訳し方

子ども向けに再話された昔話集で、繰り返し(積み上げ話)、方言、韻文の呪文が多い。既訳 5 話に合わせて、地の文は「た」で結び、語り手が聞き手に話しかける口調(「何を見たと思う?」)はそのまま残した。

- **積み上げ話**: 004「おばあさんと子豚」、016「ティティねずみとタティねずみ」、020「ヘニーペニー」、032「ふしぎな客」は、原文の繰り返しを一語も省かずに訳した。段落数も原文どおり
- **名前**: 動物の重ね名(Henny-penny, Cocky-locky, Foxy-woxy)はカタカナにして「めんどりのヘニーペニー」のように種類を添えた。Cap o' Rushes は「いぐさ頭巾」、Laidly Worm は「醜い竜」と意味で訳し、Tom Tit Tot・Nix Nought Nothing・Childe Rowland・Burd Ellen はカタカナにした
- **韻文と呪文**: Fee-fi-fo-fum は「フィー・ファイ・フォー・ファム」、Nimmy nimmy not は「ニミー ニミー ノット」と音を残し、意味のある韻文(ビノリーの竪琴の歌、赤いエティンの歌、トム・サムの墓碑銘)は意味をとって訳した
- **ト書き**: 032 の _gruffly_ などは、既訳 010 に合わせて「(_ぶっきらぼうに_)」と下線記法ごと残した
- **訳文にラテン文字を残さない**: 031 の「Edward III.」「Henry V.」は「エドワード三世」「ヘンリー五世」、船名 _Unicorn_ は「_ユニコーン号_」とした。ラテン文字 2 字以上の grep は、新しい batch 14 本で話の ID 以外に当たらなかった
- **数字**: この本は数をほとんど英語の単語で書いている。数字があったのは 031 の 1780 だけで、段落内に数が一つなので漢数字にした
- **原文の揺れ**: 017 で Jack が一か所だけ John になっている、003 で watchmaker と jeweller が同じ人物を指す、などの原文の不統一は直さずに写した
