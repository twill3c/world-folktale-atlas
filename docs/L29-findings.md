## 2. この本の性格と訳し方

トルコの昔話を英訳した本で、「わたしの母がわたしの娘だったころ」のような語り出しの決まり文句と、「行く前に『主の祈り』をひとつ唱えよう」「アッラーがみなさんの望みもかなえてくださいますように」という結びがつく。既訳 5 話に合わせて、地の文は「である/た」調、Padishah は初出を「王(パーディシャー)」としてあとは「王」、Mufti は「宗教長官(ムフティー)」、Peri は「ペリ」、efrit は「イフリート」、Lala は「ララ」とした。

- **名前**: 英訳が意味で訳した名は日本語の意味で訳した(Boy-Beautiful は「美少年」、Half-man-riding-on-the-worse-half-of-a-lame-horse は「足の悪い馬の悪いほうの半身に乗る半人間」、Earless は「耳なし」)。人名・地名はカタカナ(アレオドル・クライエッサ・ゲオノエア・スコルピア・チャムパラク・チーン・イ・マーチーン・バフティヤール・ベイ)
- **トルコ語の挨拶**: 002 の Selamun aleykyum は「セラームン・アレイキュム」、Ve aleykyum selam は「ヴェ・アレイキュム・セラーム」とカタカナにした(ラテン文字 grep に当たらないように)
- **脚注番号**: 原文の `[4]` `[14]` などは、既訳(009・016)と同じくそのまま残した。002 の第 1 段落は `[4]` と `[5]` の二つの数を含み、T-JA-06 の対象になるが、脚注番号がそのまま残るので通る。照合スクリプトに「原文と訳文で脚注番号の並びが一致するか」を足し、16 話とも不一致 0
- **差別的な表現**: 原文の negro・Moor・Jew は「黒人」「ムーア人」「ユダヤ人」とした(L19・L26 の方針)。018 で lame horse を最初「びっこの馬」、hideous cripple を「片輪者」と書いてしまったので、取り込み前に「足の悪い馬」「足の萎えた醜い怪物」に直し、新しい batch 16 本にこの種の語が残っていないことを grep で確かめた

## 3. 取りこぼしの確認

HC-301 のとおり、残りは途中(13 話を書いた時点)とビルド前に、index.json の未訳 ID − 書いた batch の ID(部分番号を外して数える)で計算し、残り 0 を確かめてからビルドした。取り込み件数は 16 増えて 607、`progress.json` のアナトリアは 21/21。ラテン文字 2 字以上の grep は、新しい batch 16 本で話の ID 以外に当たらなかった。段落数は原文の段落ごとに照合した(不一致 0)。

**既に公開済みの訳に残っている語**: 上の grep を既存の ja.jsonl にもかけたところ、このループより前に取り込んだ GB-9368-006(「びっこの者」)と XJ-26711-003(「びっこを引いて」)に同じ種類の語があった。このループの範囲外なので直していない。
