# L3 実測記録(2026-09-08)— 解析成果と Web

## 1. 検査が全部緑のまま壊れていた三件

どれも例外を出さず、JSON は正しく、型検査も通り、テストも書ける形をしていた。
**壊れていたのは値の分布だけ**である。見つかったきっかけは、
有名な話を数件開いて目視したことだった。

### (1) ドイツ語 62 話すべてでテーマが 0 件だった

テーマとモチーフは「ラベルの説明文との Embedding 類似度」で当てている。
説明文は英語で書いた。類似度を**全話まとめて** z 化していたため、
ドイツ語の話はどのラベルに対しても系統的に低く出た。

| 言語 | 無付与率(修正前) | 無付与率(修正後) |
|---|---|---|
| 英語 299 話 | 0.415 | 0.161 |
| ドイツ語 62 話 | **1.000** | 0.161 |

これは L2 で測った「言語をまたぐと平均類似度が 0.05 下がる」の、そのままの帰結である。
**測ってあったのに、使うところで効かせ忘れていた。**
修正: z 化を言語ごとに行う。

### (2) 出来事の推定が Family に偏っていた

区画ごとに引き金語の**生の回数**が最大のものを採っていた。
`father / mother / brother / sister` を引き金に持つ Family がほぼ全区画で勝った。

| 指標 | 修正前 | 修正後 |
|---|---|---|
| 最頻イベントの占有率(該当ありの中で) | **0.583** | 0.106 |
| 出たイベントの種類 | 実質 数種 | 17 種 |

ありふれた語ほど強く出るのは、物語の構造ではなく**語の頻度**を測っているということである。
修正: コーパス全体の出現率で割った比(lift)を使い、1.5 倍未満は「該当なし」とする。

### (3) 人物抽出が `This` `Hither` `You` を人物にしていた

大文字で始まる語の頻度で人物を推定していた。文頭と台詞の頭も大文字になる。
さらに**ドイツ語は普通名詞をすべて大文字で始める**ので、
`Großmutter`(祖母)`Wald`(森)が人物として出ていた。

修正:
- ドイツ語では**出さない**(間違ったものを出すより、出さないほうがよい)
- 英語でも、その語がコーパス中で小文字としてよく出るなら固有名ではないとみなす

副作用として、狼・狐のように普通名詞で呼ばれる登場人物は拾えなくなった。
画面にはその旨を書いてある。**「登場人物」ではなく「固有名の候補」と呼ぶ。**

## 2. 起票(HC-227)

`GEN-LOGIC` が 2 回でツーストライク(LL-10)。共通の型は

> **スコアの基準線が、測りたいものと別の量(言語・語の頻度)に依存している**

規範の追加を提案した:

> 分類器・ラベル付け器を出荷する前に、**群ごとの無付与率**と
> **付与ラベルの頻度集中**を数えてログに残す。
> 一件ずつ目で見て納得することは、この検査の代わりにならない。

本プロジェクトには `ml/analyze.py` の `label_distribution()` と
`tests/test_analysis.py` で先行適用した。

## 3. 地図から外部タイルを外した

設計書 §35 は MapLibre GL JS を第一候補とするが、採らなかった。

- タイル提供者は API キーと従量課金を伴う(SPEC N-01「課金経路を持たない」に反する)
- 閲覧者のブラウザから第三者へリクエストが飛ぶ

代わりに Natural Earth 10m Admin 0(パブリックドメイン)の国境を
0.6° 格子に丸め、面積 3 度² 未満の環を落として **241 KB** にし、自前の SVG で描いた。
本アプリの地図が必要とするのは 11 の文化圏の位置関係だけで、道路も地形も要らない。

### ラベルの重なりは「他の印の円」も避けないと解けない

ラベルどうしの衝突だけを見ていたときは、**日本のラベルが朝鮮半島の円に重なっていた**。
円を障害物として扱い、縦に逃がして引き出し線を引く形に直した。
緯度の描画範囲も 78°N〜56°S に切った(南極まで描くと余白ばかりになる)。

## 4. 群のまとまりは弱い(隠さずに書く)

HDBSCAN で 15 群 / 未分類 21 話。**シルエット係数 0.060**。
文章の Embedding では珍しくない値だが、
「くっきり分かれた群が見つかった」という見せ方はできない。
画面にはこの数字と「境目に意味を読み込んではいけない」を書いた。

一冊だけから成る群には、画面上で警告を出している
(地域の共通性ではなく、その本の文体をまとめている可能性が高い)。
