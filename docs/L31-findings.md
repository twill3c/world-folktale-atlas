## 1. 範囲

L30 のあと、未訳の語数がいちばん少なかった文化圏はハワイだった(19 話・58,735 語)。一話の長さの幅が大きく、1,256 語から 8,717 語まである。段落の多い 014「カアラとカアイアリイ」(83 段落)と 008「カレレアルアカ」(135 段落)は、部分番号つなぎで `#1`・`#2`(014)、`#1`〜`#3`(008)に分けて書いた。

## 2. この本の性格と訳し方

ハワイの伝説を、宣教師の子孫や土地の語り部の書いたものから編んだ本で、伝説そのものと、それを紹介する編者の解説文が同じ話のなかに混ざる。既訳 5 話に合わせて、地の文は「である/た」調、固有名はカタカナ、ハワイ語の語は初出でカタカナ+括弧の意味(カパ(樹皮の布)、イム(地の竈)、カフナ(祈祷師)、アリイ(首長)、コノヒキ(差配人)、パリ(断崖))とした。

- **ラテン語の学名**: 原文は `_Metrosideros polymorpha_` のように斜体の学名を括弧で添える。ラテン文字 grep に当たるので、すべてカタカナにした(メトロシデロス・ポリモルファ、アレウリテス・モルッカナ、アカシア・コア、ユウゲニア・マラケンシス、パンダヌス・オドラティッシムス、マバ・サンドウィケンシス、カシエンピス・サンドウィケンシス、カロフィルム・イノフィルム、コロカシア・アンティクオルム、カラジウム・コスタツム)
- **章番号と話者の頭文字**: 001 の `I.--SNARING THE SUN` は「一 ——太陽を捕らえる」。008 の問答は原文が `K.` `M.` と頭文字で話者を示すので、「カレ」「マリ」と名の頭をカタカナで書いた
- **ハワイ語の唱えと諺**: 009 の神々への呼ばわりはカタカナで音を写し、括弧で意味を添えた。原文が英訳を添えている諺(「ヘ・ポ・ホオカヒ、ア・アオ・ウア・パウ」など)は音+原文どおりの訳
- **脚注番号**: 原文の `[4]`〜`[8]` はそのまま残した。照合スクリプトで原文と訳文の並びを突き合わせ、19 話とも不一致 0

## 3. 取りこぼしの確認

HC-301 のとおり、残りは途中(14 話を書いた時点)とビルド前に、index.json の未訳 ID − 書いた batch の ID(部分番号を外して数える)で計算し、残り 0 を確かめてからビルドした。取り込み件数は 19 増えて 639、`progress.json` のハワイは 24/24。ラテン文字 2 字以上の grep と、L30 で語を足した差別語 grep は、新しい batch 19 本で当たり 0 だった。段落数は原文の段落ごとに照合し、19 話とも一度の書き直しもなく一致した。

## 4. 検査が赤くなった——原因は和訳ではなかった

取り込み後の検査で `npm run verify` が `Cannot find module '@huggingface/transformers'` で落ち、スモークが `/gates/` の目印「H-05a」「H-05b」「H-06」を見つけられずに落ちた。

このループのあいだに**別セッションが DL 三本のブランチを main に取り込んで**いて(`09f4f1c` と `96287d9`)、新しい依存と新しい検品項目が入っていた。手元の `node_modules` が古いままだったので、型検査が落ち、ビルドが更新されず、スモークが新しい目印を見つけられなかったのである。`npm install` を実行すると三つとも緑になった(テストも 45 件から 75 件に増えていた)。

**和訳のループでも、他セッションのコミットが main に入っていれば依存は変わる。** 検査が落ちたらまず自分の変更を疑うが、変更したファイルが `data/translations` と `public/data` だけで型検査が落ちたなら、それは自分のせいではない。`git log` を見て、`npm install` を先に試す。
