## 2. この本の性格と訳し方——**英訳された日本の昔話を日本語に戻す**

これまでの 22 文化圏と決定的に違うのは、**原話が日本語で、訳す先にも同じ話が生きている**ことである。桃太郎・浦島太郎・かぐや姫・舌切り雀・さるかに合戦・花咲か爺・金太郎・羅生門の鬼・ヤマトタケル・松山鏡・俵藤太——どれも日本語の読者が題名で知っている。だから「英文をそのまま日本語にする」のではなく、**固有名と物の名を本来の日本語に戻す**のが仕事の中心になった。

- **人名・地名は漢字に戻す**: Hidesato → 藤原秀郷、Raiko → 頼光、Watanabe → 渡辺、Kintoki/Kintaro → 金時/金太郎、Sadamitsu → 貞光、Toyonari Fujiwara → 藤原豊成、Hase-Hime → 長谷姫、Terute → 照手の前、Katoda → 嘉藤太、Hohodemi → 火火出見、Tayotama/Tamayori → 豊玉姫/玉依姫、Shiwozuchino Okina → 塩土の翁、Ototachibana → 弟橘姫、Miyadzu → 宮簀姫。地名も Seta-no-Karashi → 瀬田の唐橋、Echigo → 越後、Idzumo → 出雲、Usui Toge → 碓氷峠、Yaidzu → 焼津
- **確かでないものはカタカナのまま**(L12〜14 の中国本と同じ規則): 022 の中国の武将 Hako・Eiko・Kokai はカタカナ、確かな 女媧・伏羲・祝融 だけ漢字
- **物と決まり文句も日本語に戻す**: rice-dumpling → 握り飯、wen → 瘤、mortar → 臼、tamate-bako → 玉手箱、Jewels of the Ebb and Flow → 潮干る珠・潮満つ珠、“Chin, chin!” → 「ちんちん!」、“don, don”/“meri, meri” → 「どんどん」「めりめり」
- **英訳者の比喩は残す**: 021 の「テニスの球ほどの瘤」、002 の「イギリスでするように鏝を当てる代わりに」など、1908 年の英語読者に向けた言い方は均さずそのまま訳した。これは「この本は英訳である」という事実を消さないため

## 3. 脚注の形が前ループと違った——照合スクリプトが捕まえた

ルーマニア本の脚注段落は `[Footnote 4: …]` という形で、数字が `[n]` の形にならないので、訳文では 〔注4 …〕 と書いてよかった。**オザキ本の脚注段落は `[1] An alcove where…` の形**で、照合スクリプトの `\[(\d+)\]` に当たる。そのため 002 で 〔注1 …〕 と書いたところが footnote-mismatch として落ちた。訳文でも `[1] 貴重な品を飾る床の間のこと。` と、原文と同じ形に直した。

**本が変われば脚注の書式も変わる。** 前のループの書き方をそのまま持ち込まず、最初の 1 話で照合を通してから残りを書く。
