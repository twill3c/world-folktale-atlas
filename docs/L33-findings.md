## 2. この本で決めた訳しかた

前の本(オザキ本・ルーマニア本)の流儀をそのまま持ち込まないこと。この本には
この本の形がある。

- **結びの定型**は全話共通で「ここでわたしの話はおしまい。ナティヤの棘は枯れゆく、云々。」
  既訳の IN-38488-022 に合わせた。原文が `Thus my story endeth` のときは「こうしてわたしの話はおしまい。」
- **話者札の対話**は「名——」の形。`Rajah.` → 「ラージャー——」、`Phakir's Mother.` → 「ファキルの母——」。
  017 番台の二羽の鳥も同じく「ビハンガマ——」「ビハンガミー——」
- **脚注番号は原文の形のまま残す。** この本の脚注は `[43] sannyasi` のように
  本文中に `[n]` が立つので、訳文でも `サンニャーシ [43]` と同じ位置に置く
- **インドの語はカタカナ+必要なら括弧の説明。** ラクシャシー(女の羅刹)、パクシラージ(鳥の王)、
  ガムチャ、チャルパーイ、トゥラシ、ガート、ダシ、マニキャ、スファティカスタンバ
- **長い一段落は一段落のまま。** 原文の [11] や [48] は数千語の一段落だが、
  読みやすさのために割らない(段落数が合わないと取り込まれない)
- **韻を踏む呼ばわり**は音を写して残す。`How, mow, khow!` → 「ハウ、マウ、カウ!」、
  `Hye, mye, khye!` → 「ヒェ、ミェ、キェ!」、`dhoop! dhoop!` → 「ドゥープ! ドゥープ!」

## 3. 検査が捕まえたこと

`scratchpad/chk33.py` を 1 話ごとに、書いた直後に走らせた。見るのは
段落数・多数字の脱落・脚注番号の照合・ラテン文字の残り。

- **英単語が訳文に残った**(0285 / IN-38488-009 段落 0)。
  「昼も夜も religious な——いや、宗教の行と神への瞑想に明け暮れていた。」という下書きの跡。
  検査の前に自分で読み返して見つけた。検査の `[A-Za-z]{2,}` はこれを捕まえる網である
- **脚注番号の照合は本ごとに形が違う。** ルーマニア本は `[Footnote 4: …]` で `\[(\d+)\]` に当たらないが、
  この本は `[43]` で当たる。L32 で学んだとおり、最初の 1 話で検査を通してから残りを書いた
- 17 話すべて、段落数・脚注・多数字とも指摘ゼロで通った

## 5. 差別語の grep

新規バッチ 17 本と、公開済みの `data/translations/ja.jsonl` 全体の両方に
`(?<!ち)びっこ|片輪|不具|廃疾|白痴|低能|めくら|つんぼ|気違い|気狂い|土人|支那` をかけ、
**どちらも 0 件**。

`grep -P` はこの機の locale で日本語に使えない(`-P supports only unibyte and UTF-8 locales`)ので、
Python の `re` で回し、当たった文字列は前後 12 文字を出して目で見る形にしてある。
数だけ見ない(L30 の「ちびっこ熊」の教訓)。
