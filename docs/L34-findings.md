## 2. この本で決めた訳しかた

- **段落 0 は必ず語り手の名と土地**。`Henry Spence, Bog, Westmoreland.` → 「語り手 ヘンリー・スペンス(ウェストモーランド、ボグ)」。
  既訳 5 話(041/047/048/050/093)に合わせた
- **クレオールは砕けた話し言葉で写し、日本語の方言には寄せない**(L10 で決めた方針の踏襲)
- **`Jack man dora!` は結びの決まり文句**。「ジャック・マン・ドーラ!」と音を写し、訳さない。
  綴りの揺れ(dora / dory / dori)は日本語でも揺らしたまま残す
- **`Brer`/`Brar`/`Bredder` は「〜どん」**。虎どん、犬どん、山羊どん。アナンシは「アナンシどん」
- **意味が筋に効く名は訳す。** Look-up-in-de-sky →「空を見上げろ」、Cunnie-mo'-than-father →「父より賢い」、
  Big-Belly / Maugre-Foot →「大腹」「痩せ足」、Fling-a-mile →「一マイル投げ」
- **囃し言葉・呪文は音を写す。** 「ジャック・マン・ドーラ」のほか
  「ケリー・バム・ボム・バ」「ティンボ・リンボ」「ジンゲレイ」「ホック カラック カム カ タム 呑み込め」
- **ジャマイカ固有の語**: John-crow →「ジョン・クロウ(禿鷲)」、duppy →「亡霊/ダッピー」、
  Old Witch →「妖術使い」、Busha →「差配」、pen →「牧場」、Dry-head →「乾き頭」、
  yabba →「土鍋」、cutacoo →「背負い籠」、packey →「瓢箪」
- **異話 a/b/c は一つの話の中に入っている。** 見出し行(`a. The Tar Baby.`)も語り手行も
  そのまま 1 段落として訳す。同じ話に語り手が 2〜4 人いることがある

## 3. 検査が捕まえたこと

`scratchpad/chk34.py` を 1 バッチごとに走らせた。見るのは段落数・多数字の脱落・脚注番号の照合・ラテン文字の残り。

**捕まえた 4 件は、すべて自分では見落としていたものである。**

| バッチ | 指摘 | 中身 |
|---|---|---|
| 0303 | ラテン文字 `country` | 「アナンシさんと羊さんが country を歩きに」——下書きの跡。「在所」に直した |
| 0304 | ラテン文字 `fig` | 「蜘蛛どんは figい調子で」——`too fast` を訳しかけて残した。「調子がよすぎる」に直した |
| 0309 | 脚注順序 `[1]` | 原文 `Busha [51] in one pen [52]` に対し訳が「牧場 [52] の差配 [51]」で順序が逆。文を二つに割って順序を合わせた |
| 0310 | 差別語 `黒んぼ` | 後述 |

**脚注番号は「同じ番号があるか」ではなく「同じ順序で並ぶか」まで見る検査だった。**
日本語は修飾の向きが英語と逆になるので、語順を入れ替えると番号の順序も入れ替わる。
0309 はそれで落ちた。数が合っていても順序で落ちうる、と覚えておく。

## 4. 差別語 grep を広げたら、公開済みの訳に 1 件当たった

**今回 `黒んぼ` を正規表現に足した。** すると 2 か所に当たった。

1. **新規バッチ 0310(JM-72735-053)**。原文は `Me know nigger fe nigger!`。
   原文自体が差別語で、ジャマイカの語り手が内輪で使ったもの。
   L19 の方針(原文の蔑称を日本語の蔑称に置き換えない)に従って「黒人のことは黒人が知ってるぞ」とした
2. **公開済みの batch-0056(ZA-35557-001、南アフリカ)**。
   原文は `this stupid old black one` で、**英語のほうには蔑称がない**。
   訳文が差別語を持ち込んでいた。「この愚かな年寄りの黒人は」に直して再ビルドした

**教訓は「網を広げると、前のループで通ったものが落ちる」。**
L30 で 3 件、今回 1 件。regex に語を足すたびに公開済み `ja.jsonl` 全体を引き直す。
最終確認では **incoming の全バッチ**にもかけた(公開前の訳を含めて 0 件)。

grep は Python の `re` で回す(`grep -P` はこの機の locale で日本語に使えない)。
当たった文字列は前後 14 文字を出して目で見る。数だけ見ない。
