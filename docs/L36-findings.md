バッチは `batch-0341.json`〜`batch-0364.json` の 24 本。

## 2. この本で決めた訳しかた

マグナスは民話の口調を残すためにきわめて素朴な英語を使い、脚注に露語の語釈を置く。
この本の訳しかたは、その素朴さと決まり文句の反復を崩さないことに尽きる。

- **決まり文句は毎回同じ日本語で返す。** 「三九の国の彼方、三十番めの王国に」、
  「話すのはたやすいが事を成すのはたやすくない」、「朝は夕より賢い」、
  「どんな話も語り尽くせず、どんな筆も書き尽くせぬ」、
  そして結びの「わたしもそこにいて蜂蜜酒を飲んだ。髭までは流れてきたが口には入らなかった」
- **同じ問答が三度繰り返される話では、三度とも同じ言い回しにする。**
  英語が一語だけ変わっているときは、日本語も一語だけ変える(054 の
  「梭子魚のよき心のまま」に続く行が by/of/at で揺れるのをそのまま移した)
- **露語はカタカナ+脚注の位置を保つ。** イズバー/シューバ/グースリ/クワス/カフタン/
  サラファン/ボヤーレ/バーブシュカ/バーチュシュカ/ツァレーヴィチ/コロリェーヴィチ、
  度量衡はヴェルスタ/サージェン/プード
- **名の意味が筋に効くときだけ訳す。** 「不運者ダニーロ」「笑わぬ姫」「シラナイ」
  (Donotknow)「悲嘆」(Sorrow)。人名のままでよいものは音写のみ
- **時代の偏見語は原文どおり。** 006 の "gipsy" は「ジプシー」、019 の
  「ユダヤ人がキリストを十字架につけた国」もそのまま(L19/L25 の方針)

## 3. 検査が捕まえたこと

`scratchpad/chk36.py` を 1 バッチごとに走らせた。見るのは段落数・多数字の脱落・脚注番号の照合・ラテン文字の残り。

| バッチ | 指摘 | 中身 |
|---|---|---|
| 0349 | ラテン文字 `healthy` | 推敲の残骸。「その同じ瞬間に息子は healthy——いや、すっかり健やかになった」を直した |
| 0360 | ラテン文字 `span` | 原文 `a span length between his brows` の単位を訳し忘れていた。「一あた」に直した |

**この本は数がすべて英語の綴りで書かれている**(thirty thousand、twelve chains、
five hundred roubles)ので、T-JA-06 の対象になる段落が一つも出なかった。
脚注も一段落に一つずつで、順序の入れ替わりは起きなかった。
段落数は 67 話すべて一致した。

## 4. 差別語の grep ——**前回の記録が実測と食い違っていた**

今回のバッチは 0 件だったが、**incoming 全体と公開済み `ja.jsonl` に「乞食」が 77 件あった。**

L35 の記録(docs/L35-findings.md §4)には「今回『乞食』を正規表現に足した。
新規バッチ・incoming 全バッチ・公開済み `ja.jsonl` のいずれも 0 件」と書いてある。
だが今回同じ語を含む正規表現で引くと 77 件出た。**前回の grep は実際には効いていなかった。**

当たった 77 件は 27 バッチ・21 話にまたがり、英語原文はいずれも中立語の `beggar` だった。
**訳文が差別語を持ち込んでいた**——L35 の南アフリカ訳「黒んぼ」(原文 `this stupid old black one`)と同じ構図である。
77 件すべてを「物乞い」に置換し、再ビルドして incoming・`ja.jsonl` とも 0 件を確認した。

**教訓が二つある。**

1. **grep を走らせた記録は、走らせた結果の証拠にならない。** 「0 件だった」と書いた次のループで
   同じ網を引き直すと 77 件出た。ループごとに引き直す運用(L35 で決めたこと)は正しかったが、
   **前回 0 件だったから今回も 0 件のはず、と考えなかったのが幸いした。**
2. **原文が中立語でも訳語の選択で差別語が入る。** `beggar` も `cripples`(071)も英語では蔑称ではない。
   今回のロシア訳では最初から「乞う者」「体の不自由な者」を使っていたので新規 0 件だったが、
   過去 21 話は「乞食」「不具」を選んでいた。**網は原文ではなく訳文にかける。**

`grep -P` はこの機の locale で日本語に使えないので Python の `re` で回し、
当たった文字列は前後 14 文字を出して目で見る形にしてある。

## 5. HC-301 の差し引き

30 話めで中間確認(残り 37 話・53,159 語)、書き終えてから最終確認(残り 0)。
取り込み後に `progress.json` のロシア `done == total == 72` を照合した。

**索引の 67 話と `progress.json` の 72 話は食い違わない。** 索引で未訳だったのが 67 話、
既訳が 5 話(046/060/067/068/069)で、合わせて 72 話である。
