## 1. 訳語の決め方(Dasent 1859)

この本にはすでに 5 話の訳があったので、その言い回しに合わせた。

- 段落の末尾が会話で終わるときは **「」の内側に 。を置く**(既訳に合わせた)
- "Once on a time" は **むかしむかし**
- **筋に効く名は訳す**: True/Untrue → まこと/いつわり、Shortshanks → 短脛、
  Mastermaid → 名人娘、Farmer Weathersky → 天気百姓、Tatterhood → ぼろ頭巾、
  Katie Woodencloak → 木の衣のカティ、Bushy Bride → 藪の花嫁、
  Big Peter/Little Peter → 大ペーテル/小ペーテル、Big Bird Dan → 大鳥ダン
- **ただの名は音で写す**: Boots → ボーツ、Dapplegrim → ダップルグリム、
  Ritter Red → 赤のリッテル、Bruin → ブルーイン、Reynard → レイナード、
  Soria Moria → ソリア・モリア、Halvor → ハルヴォル
- 韻を踏む渾名の連なり(Henny-Penny / Cocky-Locky / Ducky-Lucky / Goosey-Poosey /
  Foxy-Cocksy)は**音で写した**。訳すと韻が消え、韻こそがこの話の中身だから
- "HUTETU" は **フテトゥ!**、the Deil は **悪魔**
- 地口の連なり(018)は、**両方の意味を持つ日本語**で受けた
  (match/mate → 相手、tongue/sole → すり減る、crooked words/horn → 曲がる)

## 3. 差別語 grep — 今回は訳文に持ち込みかけたものを 2 件つかまえた

L36 の教訓(**grep を走らせた記録は走らせた結果の証拠にならない。網は原文でなく
訳文にかける**)に従い、毎バッチではなく最後に新バッチ・incoming 全体・
公開済み `ja.jsonl` の三か所すべてに引き直した。結果は **三か所とも 0 件**。

ただしそこに至るまでに、下書きの段階で 2 か所、**英語では中立な語から差別語が
生まれかけた**のを自分で見つけて直している。

| 原文 | いったん書いた訳 | 直した訳 |
|---|---|---|
| `he'd better turn into the madhouse`(046) | 気違い病院 | 正気を失った者の入る所 |
| `If I hadn't been drunk and mad`(046) | 気が違っていなければ | 正気を失っていなければ |

英語の `mad` は罵りでも診断でもない日常語だが、日本語の対応語は差別語になる。
L36 の `beggar`・`cripples` とまったく同じ形である。**訳語を選ぶ瞬間が唯一の関所**で、
grep は取りこぼしを拾う網にすぎない。

## 4. ラテン文字残りを 1 件つかまえた

batch-0382(NO-8933-043)で `あなたが昨日discardした王` と書いていた。
「討ち取った」と書くべきところに英語の動詞が紛れ込んだ、下書きの残骸である。
L36 でも `healthy` と `span` で同じことが起きた。**チェッカの
`[A-Za-z]{2,}` 検出は訳の質ではなく自分の下書き事故を捕まえる網**として働いている。

今回は書いた直後に自分で気づいて直したので、チェッカに掛ける前に消えた。
検査に頼らず気づけたのは、**書いた JSON を読み返す手順を挟んだ**からで、
チェッカはその後の保険として 0 件を確認した。

## 5. 付録の序文も 1 段落として訳した

NO-8933-058 は「がちょう番のアニー」の 43 段落のあとに、
**Dasent 自身による付録(アナンシ物語)への序**が 6 段落続く構成になっている。
話の単位は著者の番号に従うという方針どおり、序も同じ話の段落として訳した。

ここには脚注 `[1]` が本文と脚注本体の 2 か所にあり、順序まで一致させた。
また `_n_ into _l_` のような**字そのものを指す箇所**は、
単字ならチェッカの `[A-Za-z]{2,}` に掛からないので
「n の音が l の音に変わる」と原文の字を残した。意味が字の形にあるからである。
