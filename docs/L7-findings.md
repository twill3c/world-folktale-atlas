## 2. 検査を、取り込む前に直した

ペロー『青髭』には、場面の区切りとして**文字が一つも無い段落**が二つある。

```
*       *       *       *       *
```

T-JA-03(全段落に日本語の文字がある)は、訳し忘れの英文を捕まえるための検査である。
しかしこの段落には**訳すべき語が無い**。訳文もそのまま写すのが正しい。
そのまま流せば、正しい訳を却下していた。

前回(L6)は T-JA-06 が漢数字の年号を数と読めず、**却下されてから**検査を直した。
今回は原文を読んだ段階で気づいたので、**取り込む前に**検査側を直した。

直し方: 原文の段落に文字(ラテン文字)が無い場合は、訳文に日本語が無くても違反にしない。

> 検査は「訳文にあるべきもの」を決めている。**原文に無いものは、訳文にあるべきではない。**
> 検査の前提が原文の側に崩れる場合を、検査は自分では知らない。
