## 2. 目次の無い本のために、分割器に二つ目の方式を足した

これまでの分割は「目次の題名 → 本文の見出し」の照合だけだった。今回の 6 冊のうち 5 冊はこれで割れない。

- アイヌ本には目次が無い
- ナイジェリア本は本文の題名を斜体の塊(`_The Tortoise with a Pretty Daughter_`)に置き、見出しの索引から外れる
- ハワイ本は目次に寄稿者名の行と、章の中の小話(`I. Snaring the Sun 31`)が挟まる

しかし 5 冊とも、**著者が通し番号を刷っていた**。そこで `split.strategy = "numbered"` を足し、
件数オラクルを二つの独立な証拠の突き合わせにした。

1. 本文の番号が 1 から欠けも重複もなく続く
2. 目次があれば、その番号付き項目の数と一致する

1 だけでは弱い。地の文の行頭の番号を見出しと取り違えても、偶然続けば通る。
実際、ナイジェリア本では前付け全体で目次の項目を数えると **73** になった
—— Lang の序文が『I. _The Tortoise…_--The story』のように話を番号つきで論じていた。
目次ブロックの中だけで数えて 40 に一致した。

## 3. 検査が全部緑のまま通ったもの

### 3.1 編者の注記が話の本文に混ざっていた(スリランカ)

Parker は話のあとに、他書との比較と異話を書き足している。

```
                                                 North-western Province.



In Folk-Tales of Kashmir (Knowles), 2nd ed., p. 86, a Prince induced …
```

件数オラクルは一致したまま。語数も字種も正常。**このまま Embedding にかけると、
話ではなく「カシミールの類話の要約」を測る。**

原文を並べて見ると、組み方に規則があった。題名と本文・本文と採話地の行の間は空行 2 行、
**注記の直前だけが空行 3 行**。採話地の行が無い話(No. 10 / 40〜44)でも同じだった。
右寄せの採話地の行、それが無ければ空行 3 行の手前で話を終え、以降を `notes` に回した。

### 3.2 既存の関数の潜在バグ(脚注の切り離し)

`_split_trailing_notes` は、末尾の `[n] …` 行の塊を脚注として切り離す。
スリランカ本の No. 64 では、**地の文の折り返しの頭に註番号が来ていた**。

```
In a little more time the Cat said to the Squirrel, "O Squirrel,
[136] I am hungry."
```

これを脚注の本体と取り違え、話を文の途中で切って、後半を丸ごと `notes` に移していた。
既存の 709 話では踏んでいなかった。註の塊は番号の行が密に並ぶ(非空行の 25% 以上)ことを条件に足した。
直したあとも既存 709 話は 1 字も変わらない。

### 3.3 同じ見出しの形が 4 通りに揺れていた(アイヌ)

`i.--_The Rat and the Owl._[B]` の形で 39 件は拾えたが、4 件が外れて件数オラクルが落ちた。

| 番号 | 本文の見出し |
|---|---|
| vii | `…for Human Beings to` + 次の行 `copulate._`(折り返し) |
| xiv | `_The Fox and the Tiger._--(No. I.)`(同じ題の話の区別) |
| xxii | `_The Man who was changed into a Fox_.`(句点が斜体の外) |
| xxxi | `…Lord of Matomai_.[E]`(句点が外 + 脚注記号) |

**件数オラクルが落ちたので見つかった。** 連番の検査が無ければ、39 話で「採れた」と思っていた。

## 4. 検査の偽陽性(HC-274)

端の検査(HC-244)が 68 件を怪しいとし、上限 25 を超えた。
新しい本の 44 件を形で束ねると、**42 件が一つの形** —— 句点のあとの閉じ括弧で終わる話 —— だった。

```
…became very friendly together.--(Translated literally. Told by Ishanashte, 11th November, 1886.)
```

アイヌ本は全話がこの採話者の署名で終わる。資料ではなく検査の前提(「文の終わり = 最後の一字が句読点」)が
崩れていた。検査を直し、陽性対照と陰性対照をテストに置いた。残る 2 件
(US-24569-001『HOW MEN WERE CREATED』、US-18450-001『I.--SNARING THE SUN』)は本文の小見出しで、
目で通して認め、上限を 26 にした。

L6 の T-JA-06(漢数字の年号を数と読めなかった)と同じ形である。**上限を 68 に上げれば通る状況だった。**

## 6. 測り直し — H-03 の判定が変わった

Embedding を全件計算し直した(977 話・6,502 チャンク。並行セッションと CPU を分け合い約 90 分)。

| ID | L7(709 話) | **L8(977 話)** |
|---|---|---|
| G-05 交差言語 P@1(英語版グリム 64 話から) | 0.731 | **0.731** |
| 同(英語全話から) | 0.462(647 話) | **0.462**(915 話) |
| G-06 二実装照合 | 通過 | **通過**(`tests/test_embedding.py` 6 件) |
| G-07 本内 vs 本間 Cohen d | 0.772 | **0.768** |
| H-03 地理と意味 r | 0.246 | **0.231** |
| H-03 置換検定 p | 0.012 | **0.001** |
| H-03 有効標本 | 21 冊 | **27 冊** |
| H-03 判定 | 判定できない | **地理と意味に相関がある** |

**判定の帯(p < 0.01 で成立、0.01〜0.10 は保留)は L1 で登録したまま動かしていない。**

### 6.1 変化は本を足した効果か、計算し直した揺れか

全件を計算し直したので、既存の話のベクトルも少し動きうる。そこで**新しい Embedding のまま、
L4 の 21 冊だけで H-03 を測り直した**: r = 0.2433、p = 0.0122 で「判定できない」。L4 を再現した。
p が 0.012 → 0.001 に下がったのは 6 冊を足したためである。r は 0.246 → 0.243 と 0.003 動いた(計算し直しの揺れ)。

### 6.2 同じ仮説を 3 回見ている

11 冊 → 21 冊 → 27 冊と、本を足すたびに同じ検定を見た。見るたびに偶然「成立」に入る機会は増える。
3 回分として p を 3 倍しても 0.003 で、帯の中にある。一冊抜きの r は 0.193〜0.254 で符号も変わらない。

なお、本を足したのは H-03 を通すためではなく、利用者の依頼(ロシア・アイヌ・その他の空白の地域)による。
それでも「通るまで足した」と区別できる証拠は手元に無いので、ここに経緯を書いておく。

### 6.3 それでも言わないこと

**「地理が近いから似ている」とは言わない。** 近い土地の本は翻訳者・時代・編集方針も近いことがあり、
H-02 の本の効果(d = 0.77)も大きい。このコーパスでは一冊が一地域なので、両者を切り離せない。
言えるのは「本をまたいで比べても、地理的に近い文化圏の本どうしは意味的にも近い傾向がある」までである。

### 6.4 見出しが古いまま残るところだった

`/gates/` とトップページの H-03 の**数値は gates.json から出ていたが、見出しと本文は「判定できない」と直書き**だった。
判定が変わると「p = 0.001 … 判定できない」という画面になる。見出しを評価スクリプトの判定文字列から出すように直した。
検品の目印(`smoke.mjs` / `live.mjs`)も「判定できない」を探していたので、新しい見出しに合わせた。
